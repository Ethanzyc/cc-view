搁置（Snooze）功能原型 v2 — HUD + Overlay

独立原型，未改项目源码。复刻 cc-view token 与状态图标。v2 改动：① 待介入内按项目聚类（二级小标题）；② Overlay 补齐 ago 时间 + perm 橙边 + fresh 蓝点（与 HUD 一致）；③ 搜索重写（扁平列表 + 匹配高亮 + 结果计数）；④ dead 限 3 个，更早的折叠；⑤ 已搁置行保留 cc 真实状态文字。
  • 显示名称：行标题 = Session.name（Claude Code 数据源提供，如 "cc-view-94" 派生名 / 任务描述）。原型为 mock。
  • 排序：状态档（等权限>等输入>工作>Shell>压缩>搁置>已退出）→ 项目聚类 → 时间近的靠前。
  • 待定：项目小标题显示完整路径还是只 tail（~/ai/fang）？dead 上限 3 合适吗？
